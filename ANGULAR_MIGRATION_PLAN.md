# Перенос публичной части «Выпечки у Миланы» — выполнено

## Исходник и границы

Рабочая ветка: `feat/angular-public-migration` в `/media/aozaki/ssd2/projects/cre249`. Исходный React-прототип и архив `react-prototype-baseline.tar.gz` сохранены в `/media/aozaki/ssd2/projects/milana`. Контрольные снимки React находятся в `artifacts/react/`, снимки Angular — в `artifacts/angular/`. Бриф `Milana_Figma_Make_Public_Brief.md` и визуальный справочник `guidelines/Guidelines.md` использованы как исходные материалы. Angular заменяет только публичную часть; Supabase и админка остаются отдельным следующим этапом, независимо от даты публикации сайта.

## Реализация

- Angular 22.2.1, Angular CLI/build 22.2.1, TypeScript 6.0.2, Node 22.22.3, pnpm 12.8.1, anime.js 4.2.2. Версии Angular, CLI и TypeScript закреплены в `package.json` и lock-файле.
- Standalone-компоненты, zoneless без `zone.js`, Signals для категории, формы сообщения и состояния диалога. Router лениво загружает главную, каталог, категорию и изделие; hash-маршруты работают при прямом открытии и обновлении на статическом хостинге.
- Маршрут `#/item/:slug` определяет открытое изделие. После закрытия возвращаются категория, позиция прокрутки и фокус карточки. Скрытое или неизвестное изделие показывает понятное сообщение.
- Реальные фотографии перенесены в `public/photos/`; отсутствие фото обозначено. Архив переписки и React-бэкап не входят в сборку. Исторические цены и наличие исключены из публичных данных. WhatsApp-сообщение включает изделие и выбранную начинку; личный Telegram не добавлен.
- Сохранены сливочная бумага, коричневый текст, брусничный акцент и мягкое движение. Декоративная нумерация убрана, шрифтовые роли сокращены, hero и карточки адаптированы для 360/390/1440 px. Reveal-анимация не скрывает контент до запуска JavaScript и отключает перемещение при reduced motion.
- React/Figma зависимости и Vite-конфигурация убраны из корня после успешной Angular-сборки. `.gitattributes` больше не направляет обычные изображения сайта через LFS.

## Проверка

`pnpm install --frozen-lockfile`, `pnpm test --watch=false` и `pnpm build` проверяют зависимости, данные и production-сборку. `angular.json` задаёт `baseHref: /cre249/`. Production-вывод локально обслуживается командой `pnpm preview:pages` по `/cre249/`, а `pnpm test:e2e` проверяет Playwright/Chromium: главная → каталог → категория → изделие → начинка → подготовленное сообщение → закрытие; прямую ссылку, reload, Escape, Back, фокус, быстрые переключения, reduced motion, видимость секций, размеры 360/390/1440 px, отсутствие горизонтального переполнения и загрузку фото. Сообщение не отправляется.
