# Локальные варианты главной

Ветка `design/home-compositions`, исходное состояние — `3371093`.

Запуск: `pnpm preview:design`. Сервер слушает только `127.0.0.1:8450`.

- А: http://127.0.0.1:8450/#/design/a — витрина нескольких изделий, категории и короткий блок обращения.
- Б: http://127.0.0.1:8450/#/design/b — сборка медовика крупным планом, готовое изделие рядом, затем два изделия к столу.
- В: http://127.0.0.1:8450/#/design/c — фактура сливочно-карамельного пирога, его подробности и выбор других изделий.

Общая шапка, контакты, каталог и диалог переиспользуются. Товары берутся из `CatalogStore`, который запрашивает только опубликованные записи. Изображение процесса — подтверждённая сборка медовика из архива. Новые фотографии и данные не публиковались.

Основная главная остаётся на `#/`. Конфигурация `design` заменяет пустой `preview.routes.ts` на маршруты эскизов. Production использует пустой список; в его JS/CSS нет компонентов эскизов. Исходники эскизов исключены из самостоятельной компиляции production через tsconfig и подключаются только импортами конфигурации `design`.

Проверка без записи медиа: `node tests/design-preview-check.mjs`. Проверены 360/390/1440 px, загрузка фото, отсутствие переполнения, переход в изделие и возврат, обновление страницы. `pnpm build` проходит. Дополнительно проверены отсутствие эскизов в сборке и возврат к основной главной для неизвестного production-маршрута.

До выбора направления действующая главная не заменяется.
