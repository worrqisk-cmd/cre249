Скрытие изделия немедленно закрывает новое чтение записи/новую ссылку Storage, но **не отзывает уже опубликованный HTML/статические фото/кэши мгновенно**. Автоматический deploy приходит после debounce и сборки; верхняя граница при сбоях отсутствует. Приложение просит signed URL на 600 секунд; это срок его собственных запросов, не гарантия мгновенного отзыва ранее выданных ссылок. Ограничение описано в `STATIC_PAGES.md` и [документации signed URL](https://supabase.com/docs/guides/storage/serving/downloads). Оно совместимо с публичным ассортиментом, но не с размещением конфиденциальных материалов.

План: устойчивость signing → основное фото и «На главной» → памятка/backup/ответственный за PAT → оптимизация фото по измерениям. Ни одно исправление в этом аудите не реализовано.
