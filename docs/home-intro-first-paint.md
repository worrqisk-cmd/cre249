# Главная перед интро: устранение вспышки

## Причина

Production HTML содержит prerender главной. Декоративный HomeIntro создаётся только после загрузки модулей, site-config.json и первой NavigationEnd Angular. До этого браузер успевал показать главную.

До исправления тест с задержанными JS-модулями на viewport 390×844 показал: prerender `.shop-intro` виден, раннего покрытия нет (`::after`: content none, position static, прозрачный background). Тест завершился ошибкой `prerendered home must be covered before Angular loads`.

## Исправление

В исходном HTML перед содержимым страницы небольшой синхронный скрипт определяет допустимость интро и включает пустой декоративный фон #f7f1e5 на весь viewport. Когда настоящий слой HomeIntro создан, он заменяет этот фон в том же цикле отрисовки. Длительность и композиция анимации не изменены.

Ранний фон действует только для полного открытия/обновления главной без reduced motion. Каталог, изделия, админка, возврат через историю и внутренний переход на главную его не включают. При недоступном JavaScript он не создаётся, prerender остаётся видимым. Если запуск приложения задержался более 2.1 s, фон снимается и позднее интро не запускается. Ошибка загрузки конфигурации снимает фон сразу.

Поведение посещений сохранено: полное открытие главной и reload запускают интро; возврат из каталога в том же экземпляре приложения — без повторного интро. Session storage не используется.

## Проверка

Локальный production build, `http://127.0.0.1:8447/`, Chromium, viewport 1440×844 и 390×844 (эмуляция телефона). Без видео и скриншотов.

- Новый `tests/home-intro-first-paint-check.mjs` задерживает внешние JS-модули и проверяет наличие непрозрачного раннего фона перед запуском Angular. requestAnimationFrame измерения подтверждают отсутствие непокрытого кадра главной до появления интро при первом открытии и reload.
- Внутренний переход главная → каталог → главная: нет повторного слоя и раннего фона.
- Задержка запуска до истечения watchdog: фон исчезает, поздний запуск интро исключён.
- Ошибка site-config.json: сообщение доступно, ранний фон снят.
- Reduced motion и JavaScript disabled: главная доступна, интро и раннего фона нет.
- Существующие `tests/home-intro-check.mjs`: маршруты, анимация, независимый failsafe и JavaScript disabled — прошли.
- `pnpm build`: успешно, 23 prerender-маршрута.
- `pnpm test --watch=false`: 7 тестов, 2 файла, успешно.
- `pnpm test:routing`: 23 HTTP-документа без SPA fallback, desktop/mobile, история, формы и WhatsApp — прошли.
- `HEADED=1 xvfb-run -a pnpm test:dialog-position`: повторно прошли 32 сценария закрытия изделий, положение и ширина каталога стабильны.

`pnpm test:intro` запускает старые и новые проверки. Предпросмотр включает исправление каталога b1e2e55; изменений длительности его анимации и механизма сохранения положения в этой задаче нет.

Файлы подтверждения Google/Яндекса, SEO-настройки и метаданные не изменены. Публикация не выполнялась.
