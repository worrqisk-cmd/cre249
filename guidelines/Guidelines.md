# Выпечка у Миланы — дизайн-система прототипа

Стиль: «бумажная упаковка и рецептурная карточка». Сливочная бумага с лёгким зерном, коричневый текст, приглушённый брусничный акцент, рукописные пометки, полоски «скотча».

## Типографика (все с кириллицей)
- Yeseva One — заголовки (clamp 2–7.2rem, межстрочный 0.92–1.15)
- Golos Text 400/500/600 — основной текст, 16–20px, 1.6
- Caveat — рукописные пометки, только короткие фразы

## Сетка и интервалы
Контейнер 1320px; поля 20px (моб.) / 40px (≥768). Секции 56–64px моб. / 96–112px комп. Каталог: 2 / 3 / 4 колонки, gap 16–24px. Радиусы: карточки 14px, диалог 24px, кнопки — pill. Цели нажатия ≥ 44px.

## Движение (ease = cubic-bezier(.22,.8,.24,1))
| Сцена | Реализация |
|---|---|
| Интро (1 раз за сессию, sessionStorage) | заголовок → фото маской clip-path + scale 1.06→1 (850мс) → подпись; кнопки доступны сразу |
| Секции | translateY 18px + opacity, 450мс; «Что я пеку» — шаг 60мс; «О Милане» — сначала маска фото, затем текст (+350мс); шаги — +140мс и дорисовка пунктирной линии |
| Карточки каталога | card-in 380мс, шаг 55мс, максимум 8 |
| Категории | индикатор translate/width 240мс, высота области 260мс, перезапуск без очереди |
| Открытие изделия | клон фото летит из карточки в диалог 420мс, текст stagger +160мс / 50мс |
| Закрытие | обратный полёт 280мс, затем фокус на карточку; место прокрутки сохраняется |
| Кнопки | 150мс: hover −1px, active scale .97 |
| Смена страницы | page-in 260мс, без интро |
| Световое пятно hero | 24с, едва заметно; отключено при reduced motion |
reduced motion: только прозрачность, без перемещений и бесконечных эффектов.

## Маршруты (hash, совместимо с GitHub Pages)
`#/`, `#/catalog`, `#/catalog/<категория>`, `#/item/<slug>`. Back закрывает подробности. Скрытое/неизвестное изделие → сообщение и переход в каталог.
